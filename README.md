Commitment Tracker – AI-Powered Task Management

Commitment Tracker is an intelligent web application that helps users manage tasks smarter, not harder. It uses NLP, machine learning, and rule-based logic to automatically predict task priority, evaluate urgency, and provide clear, explainable recommendations through a clean, structured interface.

✨ Features

AI-based task priority prediction

Deadline-aware urgency evaluation

NLP processing for task understanding

Hybrid ML + rule-based decision system

Explainable AI recommendations

Clean, minimal, and structured UI

Smart task sorting and status tracking

🛠 Tech Used

Python (ML & logic engine)

NLP for task understanding

Machine Learning model for priority prediction

Rule-based system for urgency evaluation

Flask / FastAPI (backend)

HTML, CSS, JavaScript (frontend)
